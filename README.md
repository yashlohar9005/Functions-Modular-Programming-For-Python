# 🧮 Calculator in Python

**Author:** Yash Sunil Lohar

A simple menu-driven **Python Calculator** program that performs basic arithmetic operations using functions, conditional statements, and user input.

This project is part of **Python Task 5** and demonstrates how to build a modular, function-based program with proper control flow and input handling.

---

## 🛠️ Tools Used

* Python
* VS Code / Any Python IDE
* Windows PowerShell / Terminal

---

## ✨ Features

* Menu-driven program
* Performs:

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Uses **functions** for each operation
* Uses **if-elif-else** decision logic
* Handles **division by zero** safely
* Accepts **user input** dynamically
* Displays result clearly
* Modular and clean code structure

---

## 🧠 Operations Supported

1. Add

4. Divide
